Ticket Handling Guide

Moderators are responsible for assisting users through support tickets. This section explains how to properly greet users, gather information, and guide them through the correct application process.

Step 1 — Greeting

Hello, how may I help you today?
Hello! What can I assist you with today?

Step 2 — Role Inquiry

What role are you applying for today?
What are you applying for here?

Step 3 — Age Verification

May I ask how old you are?
What is your current age?

Role Application Instructions

Depending on the role a user is applying for, moderators must ask for specific information or proof.

Creative Academy / Main Creative

Ask the user to send 2–3 creative clips
Ping Creative Department
Creative staff review the clips

Academy Roster

Request Fortnite tracker link
Request default dance screenshot in lobby

Semi-Pro / Pro Roster

Request Fortnite tracker
Request default dance screenshot
Ping operations for review

Content Creator

Request social media links
Ping content department

GFX / VFX

Request portfolio
Request examples of previous work

Coach

Ask how many players they coached
Ask for player tracker links

Void Grinder+

If the user does not qualify for other roles, they may be offered the Grinder+ role.

Send screenshot using support creator code Team.Void
Send screenshot showing "Void" in Epic username
Use the Void Discord tag

Blacklist Ticket Format

User: Username
User ID: Discord ID
Reason: Example — Underage

Closing the Ticket

Ask user to add "Void" to their username
Request screenshot using creator code
Assign roles
Thank them for joining
Important: Moderators must remain professional during the entire ticket process.
